# SkyCity Auckland research paper (HTML / CSS / JavaScript)

Open `index.html` in any modern browser. No server, build step or internet connection is needed.

| File | Purpose |
|---|---|
| `css/aurora.css` | The deployed Streamlit app's stylesheet, unchanged |
| `css/paper.css` | Layout for the paper, plus look-alikes of Streamlit tabs, sliders and cards |
| `js/data.js` | Generated by the pipeline (preprocessing and postprocessing output) |
| `js/main.js` | Interactions and animation |
| `build/build_data.py` | Rebuilds `js/data.js` from `build/data/raw/*.csv` |

Rebuild after changing the CSV: `pip install pandas numpy pyarrow` then `python build/build_data.py`.
The build asserts that the JavaScript simulator formula equals the Python simulator for four test scenarios.
